# Dataset

The original Gojek app review dataset is not included in this public repository due to privacy and data-sharing considerations.

The dataset contains 20,000 Gojek app reviews used for sentiment analysis.

Sentiment labels were derived from review ratings:

- 1–2 → Negative
- 3 → Neutral
- 4–5 → Positive

The complete analysis workflow, preprocessing steps, machine learning models, evaluation results, and business insights are available in the main Jupyter Notebook.
